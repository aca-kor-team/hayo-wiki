# 별풍선 (API)

**시청자가 별풍선을 보내면 서버에 효과가 발생합니다.**
요리 주문을 넣을 수도 있고, 반대로 주문을 취소할 수도 있습니다.

!!! danger "참가자는 먼저 API를 연동해야 합니다"
    `/api 연동 숲 숲아이디` 로 연동한 뒤 `/api 시작` 을 입력해 주세요.
    연동하지 않으면 주문이 들어오지 않습니다.
    → [첫 접속 시 할 일](../start/first-steps.md)

## 별풍선 개수별 효과

| 별풍선 | 효과 | 상세 |
|---|---|---|
| **10** | 하요 달고나 | 1 ~ 3개 |
| **50** | 일반 주문 | 하급 ~ 중급 **3 ~ 7개** |
| **51** | 주문 취소 | 하급 ~ 중급 **2 ~ 6개** · 받은 주문 중 **무작위**로 취소 |
| **100** | 랜덤 박스 | 1개 |
| **300** | 프리미엄 주문 | 중급 ~ 고급 **3 ~ 7개** |
| **500** | 대량 주문 | 하급 ~ 고급 **20 ~ 35개** |
| **1000** | 랜덤 박스 | 11개 |

!!! info "등급은 모두 같은 확률입니다"
    주문에 들어가는 요리 등급은 **동일 확률**로 정해집니다.
    특정 등급이 더 자주 나오지 않습니다.

## 랜덤 박스

100개면 1박스, **1000개면 11박스**가 나옵니다.

| 나오는 것 | 설명 |
|---|---|
| 강화석 **1개** | 도구를 강화합니다 → [강화](../shop/upgrade.md) |
| 귀환석 **1개** | 마을로 돌아옵니다 → [귀환석](../items/return-stone.md) |
| 마법의 뼛가루 **3개** | **3 × 3** 범위 특수 작물 즉시 성장 |
| 은 마법의 뼛가루 **3개** | **5 × 5** 범위 특수 작물 즉시 성장 |
| 금 마법의 뼛가루 **3개** | **7 × 7** 범위 특수 작물 즉시 성장 |
| 기본 요리 재료 | |
| 셜커 상자 | |
| 건차 | 청크를 등록합니다 → [토지 문서](../start/land.md) |
| 지정 요리 취소권 | 원하는 주문을 골라 취소 **(고급 제외)** |
| 지정 요리 취소권 | 원하는 주문을 골라 취소 **(고급 가능)** |
| 강제 요리 주문권 | 다른 유저를 우클릭해 **주문을 떠넘깁니다** (하급 ~ 중급 1 ~ 3개) |
| 로또 | **1,000 ~ 50,000** |
| 서버 초대권 | 다른 스트리머를 서버에 초대할 수 있습니다 |
| 직원(하요) 10분 고용권 | **10분 동안 서버장을 일꾼으로** 부립니다 |

!!! danger "인벤토리를 비워두세요"
    인벤토리가 가득 차 있으면 API로 받은 아이템은 **바닥에 떨어지니** 주의 바랍니다.

!!! warning "고용권 사용 시 운영자 호출"
    직원 고용권은 사용할 때 **운영자를 불러야** 합니다.

## 서버장에게 쏘는 별풍선

서버장(하요)에게 보내면 다른 효과가 나옵니다.

| 별풍선 | 효과 |
|---|---|
| **500** | 접속해 있는 **모든 인원에게 상자 하나씩** |
| **1000** | **2분 피크타임** — 주문이 **두 배**로 들어옵니다 |

## 주문 처리

들어온 주문은 요리를 만들어 **요리 회관**에 제출합니다.

[:octicons-arrow-right-24: 요리 제출하기](../cooking/submit.md)

!!! danger "주문을 모두 처리하면 탈출입니다"
    이 서버의 목표입니다. 주문이 쌓일수록 탈출은 멀어집니다.
