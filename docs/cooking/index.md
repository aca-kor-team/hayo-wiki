# 요리

**서버의 핵심 콘텐츠입니다.**
도마·튀김기·냄비·프라이팬·찜기·오븐 같은 조리 도구로 요리를 만듭니다.

만든 요리는 판매해 돈을 벌거나,
시청자에게 받은 **주문을 처리해 서버를 탈출**하는 데 사용합니다.

## 요리하는 순서

<div class="flow" markdown>

1.  :material-book-open-page-variant: **레시피를 배웁니다**{ .flow-title }

    레시피북으로 배워야 만들 수 있습니다. 도마 요리는 예외입니다.

2.  :material-basket: **재료를 모읍니다**{ .flow-title }

    채광 · 농사 · 낚시 · 목장으로 구하거나 상점에서 구매합니다.

3.  :material-stove: **조리 도구로 만듭니다**{ .flow-title }

    도구마다 설치 방법과 사용법이 다릅니다.

4.  :material-check-circle: **제출하거나 팝니다**{ .flow-title }

    요리 회관에서 주문을 제출하거나 판매합니다.

</div>
