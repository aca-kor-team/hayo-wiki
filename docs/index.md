# 하요 요리 서버 위키

![하요 요리 서버 — 넘쳐나는 주문! 터지는 도파민!](assets/home/banner.webp){ .banner .off-glb }

시청자가 **별풍선으로 요리를 주문**하고, 참가자가 그 요리를 만들어 냅니다.
들어온 주문을 **전부 처리하면 탈출**입니다.

!!! tip "검색으로 찾기"
    오른쪽 위 **검색창**에 `육절기`, `레시피북`, `경작지` 같은 단어를 입력하면 됩니다.
    모바일에서는 위쪽 돋보기 아이콘을 누릅니다.

## 진행 방식

<div class="flow" markdown>

1.  :material-gift: **시청자가 별풍선으로 주문합니다**{ .flow-title }

    50개는 요리 주문, 1000개는 랜덤 상자 11개입니다. 주문을 취소하는 항목도 있습니다.

2.  :material-pickaxe: **참가자가 재료를 모읍니다**{ .flow-title }

    야생에서 채광 · 농사 · 낚시 · 목장으로 재료를 구합니다.

3.  :material-stove: **요리를 만듭니다**{ .flow-title }

    레시피를 배우고 도마 · 냄비 · 오븐 같은 도구로 조리합니다.

4.  :material-exit-run: **제출하고 탈출합니다**{ .flow-title }

    요리 회관에 제출해 주문을 하나씩 지워 나갑니다.

</div>
