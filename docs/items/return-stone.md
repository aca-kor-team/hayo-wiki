# 귀환석과 초대장

자리를 옮기는 데 쓰는 아이템 두 가지입니다.

| 아이템 | 하는 일 |
|---|---|
| **귀환석** | 내가 **마을로** 돌아옵니다 |
| **초대장** | 다른 유저를 **내 위치로** 부릅니다 |

## 귀환석

위치와 관계없이 **마을로 돌아올 수 있는** 아이템입니다.
야생에서 자원을 채집한 뒤 복귀할 때 사용합니다.

### 사용법

1. 귀환석을 손에 들고 **우클릭**합니다.
2. **3초** 동안 이동하지 않고 기다립니다.
3. 3초가 지나면 마을로 이동합니다.

!!! warning "움직이면 취소됩니다"
    3초를 세는 동안 **걷거나 점프하면 취소**됩니다. 이때 귀환석은 소모되지 않습니다.
    손에서 귀환석을 내려놓아도 취소됩니다.

### 구하는 곳

| 경로 | 설명 |
|---|---|
| **건차 상점** | 마을에서 구매합니다 → [상점](../shop/index.md) |
| 별풍선 랜덤 박스 | 일정 확률로 나옵니다 → [별풍선](../api/index.md) |

## 초대장 { #invitation }

다른 유저를 **내가 있는 곳으로 부르는** 아이템입니다.

### 사용법

1. 초대장을 손에 들고 **우클릭**합니다.
2. **채팅에 부르고 싶은 유저의 닉네임**을 적습니다.
3. 상대에게 텔레포트 요청이 갑니다.
4. 상대가 **수락**을 누르면 초대장을 쓴 사람 위치로 이동합니다.

!!! info "부르는 쪽이 아니라 불려오는 쪽이 이동합니다"
    초대장을 쓴 사람은 그 자리에 그대로 있고, 수락한 상대가 그쪽으로 옵니다.
