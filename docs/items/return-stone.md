# 귀환석

위치와 관계없이 **마을로 돌아올 수 있는** 아이템입니다.
야생에서 자원을 채집한 뒤 복귀할 때 사용합니다.

## 사용법

1. 귀환석을 손에 들고 **우클릭**합니다.
2. **3초** 동안 이동하지 않고 기다립니다.
3. 채팅에 뜨는 **이동 버튼**을 누르면 마을로 이동합니다.

## 주의사항

!!! warning "움직이면 취소됩니다"
    3초를 세는 동안 **걷거나 점프하면 취소**됩니다. 이때 귀환석은 소모되지 않습니다.
    손에서 귀환석을 내려놓아도 취소됩니다.

!!! note "제한 시간"
    채팅 버튼을 **15초** 안에 누르지 않으면 귀환석이 자동으로 되돌아옵니다.
    아이템은 소모되지 않습니다.
