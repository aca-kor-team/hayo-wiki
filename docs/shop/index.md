# 상점

마을에는 다섯 곳의 상점과 정기적으로 열리는 **오일장**이 있습니다.

| 상점 | 사는 것 | 파는 것 |
|---|---|---|
| **낚시 상점** | | 물고기 |
| **건차 상점** | 토지 문서, 귀환석 | |
| **농사 상점** | 경작지 | 작물 |
| **목장 상점** | 유전자 미니 목장 | |
| **광물 상점** | | 광물 |
| **오일장** *(매시 정각 10분)* | 조미료, 특수 재료 · 다양한 재료 *(중반 이후)* | |

!!! info "광물 상점은 대장간 안에 있습니다"
    따로 떨어져 있지 않고 **대장간 건물 안**에 있습니다.

## 낚시 상점

잡은 물고기를 판매하는 곳입니다.

[:octicons-arrow-right-24: 낚시 보기](../work/fishing.md)

## 건차 상점

**토지 문서**와 **귀환석**을 판매하는 곳입니다.

| 물건 | 설명 |
|---|---|
| 토지 문서 | 청크 한 개를 등록합니다 → [자세히](../start/land.md) |
| 귀환석 | 마을로 돌아옵니다 → [자세히](../items/return-stone.md) |

## 농사 상점

**경작지**를 판매하는 곳입니다. 특수 작물은 경작지에서만 자랍니다.
경작지는 한 청크에 **256개**까지 설치할 수 있습니다.

[:octicons-arrow-right-24: 농사 보기](../work/farming.md)

## 목장 상점

**유전자 미니 목장**을 판매하는 곳입니다.
석탄 블럭 1개당 **3분** 작동합니다.

[:octicons-arrow-right-24: 목장 보기](../work/ranch.md)

## 광물 상점

채굴한 광물을 판매하는 곳입니다. **대장간 안**에 있습니다.

[:octicons-arrow-right-24: 채광 보기](../work/mining.md)

## 오일장

**직접 얻을 수 없는 조미료와 재료**를 판매하는 곳입니다.
다른 상점과 달리 정해진 시간에만 열립니다.

!!! warning "매시 정각부터 10분 동안만 열립니다"
    시간을 놓치면 다음 정각까지 기다려야 합니다.

| 항목 | 내용 |
|---|---|
| 개장 시각 | **매시 정각** |
| 개장 시간 | **10분** |
| 위치 | 마을 |

### 중반 이후 추가되는 품목

!!! info "서버 중반부터 품목이 늘어납니다"
    다양한 재료를 **개수 제한 없이 구매**할 수 있는 품목이 추가될 예정입니다.
    대신 **시세보다 비싼 값**을 치러야 합니다.

급하게 재료가 필요할 때 값을 더 주고 사는 곳으로 쓸 수 있습니다.

상점과는 별개의 건물입니다.
