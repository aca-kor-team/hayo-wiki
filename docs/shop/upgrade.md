# 강화

마을 **대장간**에서 도구를 강화할 수 있습니다.

## 강화석

강화에는 **강화석**이 필요합니다.
강화석은 **광물을 캘 때** 일정 확률로 떨어집니다. 확률은 광물마다 다릅니다.

[:octicons-arrow-right-24: 채광 보기](../work/mining.md)

별풍선 **랜덤 상자**에서도 나옵니다.

[:octicons-arrow-right-24: 별풍선 보기](../api/index.md)

## 강화 방법

마을 **대장간**에서 강화합니다.

1. 강화하고 싶은 아이템을 **칸에 올립니다.**
2. 아래의 **망치 버튼**을 클릭합니다.

!!! tip "실패해도 손해는 없습니다"
    강화에 실패해도 **도구가 사라지거나 단계가 내려가지 않습니다.**
