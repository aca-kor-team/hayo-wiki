# 명령어 모음

플레이어가 사용할 수 있는 명령어입니다.

| 명령어 | 설명 |
|---|---|
| `/인출 (숫자)` | 원하는 금액을 **수표 아이템**으로 꺼냅니다 |
| `/청크 정보` | 구매한 땅 정보를 확인하고 그 땅으로 **순간이동**합니다 |
| `/쓰레기통` | 쓰레기통을 엽니다 (`/ㅆ`, `/쓰` 로도 열립니다) |
| `/도움 (사유)` | 운영자 도움창에 메시지를 보냅니다 |
| `/api 연동 숲 (숲 아이디)` | 숲 계정과 연동합니다 |
| `/api 시작` | 별풍선 주문을 받기 시작합니다 |

## /인출

입력한 금액만큼 **수표 아이템**으로 꺼냅니다.

```
/인출 10000
```

## /청크 정보

지금까지 구매한 자신의 땅 정보를 확인할 수 있습니다.
이 화면에서 **자신의 땅으로 순간이동**할 수 있습니다.

[:octicons-arrow-right-24: 토지 문서 보기](../start/land.md)

## /쓰레기통

필요 없는 아이템을 버리는 **쓰레기통**이 열립니다.

아래 셋은 모두 같은 명령어입니다.

```
/쓰레기통
/쓰
/ㅆ
```

## /도움

**운영자의 도움창**으로 메시지가 전송됩니다.
사유를 함께 적어주시면 처리가 빠릅니다.

```
/도움 아이템이 사라졌습니다
```

## /api

숲 계정과 연동해야 시청자의 별풍선 주문을 받을 수 있습니다.

```
/api 연동 숲 숲아이디
/api 시작
```

아이디는 **괄호 없이** 그대로 입력해야 합니다.

!!! danger "반드시 연동해 주세요"
    연동하지 않으면 별풍선을 받아도 주문이 들어오지 않습니다.
