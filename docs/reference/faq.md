# 자주 묻는 일

## 접속

??? question "런처는 어디서 받나요"
    참가자에게 안내된 곳에서만 배포합니다.
    자세한 순서는 [접속 방법](../start/connect.md)에 있습니다.

??? question "런처 다운로드 링크가 방송에 나가면 어떻게 되나요"
    **노출되지 않도록 주의해 주세요.**
    런처를 받는 동안에는 화면 송출을 꺼주시기 바랍니다.

??? question "서버 주소가 뭔가요"
    입력하지 않아도 됩니다. 런처가 접속까지 처리합니다.

## 처음 할 것

??? question "토지 문서를 받지 못했습니다"
    **마을 입구 도우미 NPC**에게 말을 걸면 받을 수 있습니다.
    → [토지 문서](../start/land.md)

??? question "토지 문서를 회수하면 어떻게 되나요"
    **그 땅의 보호가 사라집니다.** 누구나 손댈 수 있게 되므로 주의가 필요합니다.

??? question "친구도 내 땅에서 건축하게 하고 싶습니다"
    등록한 땅 안에서 ++shift+f++ 를 누르면 동료 권한을 줄 수 있습니다.

## 요리

??? question "요리가 시작되지 않습니다"
    레시피를 배우지 않았을 수 있습니다.
    **도마를 제외한 모든 요리는 레시피북으로 배워야** 만들 수 있습니다.
    → [레시피 시스템](../cooking/recipes.md)

??? question "냄비를 놨는데 작동하지 않습니다"
    냄비와 프라이팬은 **가스레인지나 인덕션 위에 올려야** 작동합니다.
    가스레인지는 **라이터로 불을 붙여야** 조리가 시작됩니다.
    → [조리 도구](../cooking/tools.md)

??? question "찜기가 설치되지 않습니다"
    찜기는 **물을 넣은 소형 냄비 위에만** 설치됩니다.

??? question "배운 레시피를 어디서 보나요"
    **뒤집개**를 들고 조리 도구를 **Shift + 우클릭** 합니다.

??? question "도마 요리는 레시피북 없이 되나요"
    가능합니다. 재료를 넣어보며 직접 알아내거나, 레시피북을 구매하면 됩니다.

## 일거리

??? question "동물을 번식시켜도 되나요"
    **안 됩니다.** 동물 교배는 규칙으로 금지되어 있습니다.
    고기는 **유전자 미니 목장**으로 얻습니다. → [목장](../work/ranch.md)

??? question "특수 작물이 심어지지 않습니다"
    특수 작물은 **경작지 위에서만** 자랍니다. 경작지는 농사 상점에서 구매합니다.

??? question "경작지를 더 놓고 싶습니다"
    한 청크에 **256개(한 층)** 까지만 놓을 수 있습니다.
    토지 문서로 청크를 늘려야 합니다. → [토지 문서](../start/land.md)

??? question "낚시 미니게임에 계속 실패합니다"
    세 가지 미니게임이 무작위로 나오며 **클리어해야 물고기가 잡힙니다.**
    → [낚시](../work/fishing.md)

## 별풍선

??? question "주문이 너무 많이 쌓였습니다"
    시청자가 **별풍선 51개**를 보내면 주문이 무작위로 취소됩니다.
    **지정 요리 취소권**이 있으면 원하는 주문을 골라 취소할 수 있습니다.
    → [별풍선](../api/index.md)

??? question "직원 고용권을 받았습니다"
    사용할 때 **운영자를 불러야 합니다.**

## 기타

??? question "아이템을 잃어버렸습니다"
    `/도움` 명령어로 운영자에게 문의해 주세요. → [명령어 모음](commands.md)

??? question "건의사항이 있습니다"
    운영진에게 알려주세요.
